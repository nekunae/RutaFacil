## RutaFácil ##
Aplicación Android para planificación de rutas en Bogotá, Colombia. Permite calcular trayectos con múltiples paradas usando Google Maps y la API de Directions.

Funcionalidades

| Función | Descripción |
|---|---|
|  **Pantalla de inicio** | Pantalla de inicio. |
|  **Múltiples paradas** | Define origen, paradas intermedias y destino en un solo trayecto. |
|  **GPS integrado** | Agrega tu ubicación actual como punto de ruta con un solo toque. |
|  **Info del trayecto** | Distancia total y tiempo estimado calculados en tiempo real. |
|  **Deshacer / Limpiar** | Elimina el último punto o reinicia el recorrido completo. |
---
## Tecnologias

- **Kotlin** — lenguaje principal
- **Android SDK** — plataforma de destino (API 24+)
- **Google Maps SDK for Android** — mapa interactivo
- **Google Directions API** — cálculo de rutas y waypoints
