##RutaFácil##
Aplicación Android para planificación de rutas en Bogotá, Colombia. Permite calcular trayectos con múltiples paradas usando Google Maps y la API de Directions.

Funcionalidades

Pantalla de inicio animada con splash screen
Rutas con múltiples paradas (origen + paradas intermedias + destino)
GPS — agrega tu ubicación actual como punto de ruta
Información de ruta — distancia total y tiempo estimado
Deshacer / Limpiar puntos del recorrido
